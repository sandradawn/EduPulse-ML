## About
EduPulse is an AI-powered student performance prediction platform 
that predicts whether a student will Pass or Fail — before exams happen.
It uses a dual-predictor architecture combining academic background data 
and real-time platform engagement behavior for highly accurate predictions.

---

## What Makes This Unique
Unlike traditional systems, EduPulse uses two independent predictors:

| Predictor | Dataset | Focus |
|-----------|---------|-------|
| 🎓 Academic Predictor | UCI Student Performance | Study habits, grades, background |
| 💻 Platform Engagement Predictor | OULAD | Clicks, activity, submissions |

This combination captures both historical context and live behavior.

---

## Features
- ✅ Predict Pass/Fail outcomes with confidence score
- ✅ Risk level detection — Low / Medium / High
- ✅ Switch between 5 ML models and compare results
- ✅ SHAP-based explainability — shows top risk factors
- ✅ Batch prediction via CSV upload
- ✅ Glassmorphism UI — clean and non‑technical friendly
- ✅ REST API with full documentation

## Dataset

**1. UCI Student Performance Dataset**
- Source: https://archive.ics.uci.edu/dataset/320/student+performance
- Files needed: `student-mat.csv`, `student-por.csv`
- Place in: `data/raw/`

**2. OULAD — Open University Learning Analytics Dataset**
- Source: https://analyse.kmi.open.ac.uk/open-dataset-rdf
- Files needed: `studentInfo.csv`, `studentVle.csv`, `studentAssessment.csv`
- Place in: `data/raw/`

## Installation

**Prerequisites**
- Python 3.10+
- pip

**Clone the repository**
```bash
git clone https://github.com/sandradawn/EduPulse-ML.git
cd EduPulse-ML
```

**Install dependencies**
```bash
pip install -r requirements.txt
```

**Download datasets**
Follow instructions in `data/raw/README_DATASETS.txt`

**Train the models** (optional, models are trained on first run)
```bash
python src/models/trainer.py --dataset both
```

**Run the app**
```bash
python app/app.py
```
Open your browser at `http://localhost:5000`

---

## Usage
1. Open `http://localhost:5000`
2. Choose a tab — Academic or Platform Engagement
3. Fill in the student details (or click Demo to auto‑fill)
4. Select an ML model from the dropdown
5. Click **PREDICT**
6. View the result — Pass/Fail, confidence %, risk level, top risk factors
7. For bulk predictions — drag and drop a CSV in the Batch section

## Model Performance

| Model | UCI Accuracy | UCI F1 | OULAD Accuracy | OULAD F1 |
|-------|--------------|--------|----------------|----------|
| 🏆 CatBoost | 90% | 0.91 | 94% | 0.94 |
| XGBoost | 88% | 0.89 | 92% | 0.92 |
| Random Forest | 86% | 0.87 | 90% | 0.90 |
| MLP | 85% | 0.86 | 89% | 0.89 |
| SVM | 83% | 0.84 | 87% | 0.87 |

**Best Model: CatBoost** across both datasets.

## API Documentation

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Serve frontend UI |
| POST | `/predict` | Single student prediction |
| GET | `/models` | List all models + accuracy |
| GET | `/model-comparison` | Full model comparison JSON |
| POST | `/batch-predict` | CSV upload for bulk prediction |
| GET | `/health` | API health check |

**Example — Single Prediction:**
```bash
curl -X POST http://localhost:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"dataset":"uci","model":"catboost","data":{...}}'
```
